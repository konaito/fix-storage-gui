Sign in with ChatGPT のデモアプリ

重いファイルを見つけて、
安全にゴミ箱へ。

Fix Storage GUI は、Mac のストレージを圧迫している重いファイル・フォルダを見つけ、 最終確認のあとゴミ箱へ移動するための GUI アプリです（Tauri v2）。 完全削除はしません。 Finder の「戻す」で元に戻せます。 AI 判定には Sign in with ChatGPT を使い、ChatGPT プランの使用量で動きます（API キー不要）。

Windows・Linux には対応していません。 最新の GitHub Release（現在の v0.2.2）の .dmg は Developer ID で署名され、Apple の公証（notarization）を通しています。 開いて Fix Storage GUI.app を「アプリケーション」へドラッグしてください。

Workflow

4つのステップ

起動すると、まず ChatGPT でのサインインが必要です。 ChatGPT プランの利用を許可しなかった場合は、元 CLI のルールとハードブロックだけの判定で使えます（その場合、OpenAI には何も送りません）。

  1. スキャン対象を選ぶ

    「Mac 全体（元 CLI と同じフォルダ群）」か、任意のフォルダを選びます。

  2. AI 判定

    スキャンが終わると、AI に送る内容の確認ダイアログが開きます。 送信すると「削除していい / 注意 / 消しちゃダメ」と理由を日本語で表示します。 判定には Sign in with ChatGPT を使い、25 件ずつのバッチを最大 3 本まで同時に送ります。 ChatGPT プランの利用を許可していない場合、AI 判定は使えず、一覧は元 CLI のルールで判定します。

  3. 重いもの一覧

    サイズに比例したツリーマップ（表形式にも切り替え可）で、最終使用日（Spotlight の kMDItemLastUsedDate）、更新日、元 CLI のカテゴリと判定を表示します。 AI 判定のあとは「削除していい」ものを優先して並べます。 AI が判定していない項目は「未判定」になり、選べません。 項目を選ぶと右側に詳細と、この Mac の中だけで作るプレビューが出ます （保護対象や鍵らしいファイルは中身を開きません）。 フォルダは「中を見る」で掘り下げられます。

  4. ゴミ箱へ移動

    選んだものを最終確認ダイアログのあとでゴミ箱へ移動します。完全削除はしません。

Safety first

安全のための仕組み

このアプリの目的は「一気に消す」ことではなく、消しすぎないことです。 危険な対象は選べません。移動先はゴミ箱だけです。

完全削除はしません。ゴミ箱へ移すだけです。Finder の「戻す」で復元できます。

判定の優先順位

  1. ハードブロック
  2. ＞
  3. 元 CLI のルール
  4. ＞
  5. AI

ハードブロックは、元 CLI のルールや AI の判定より常に優先されます。 AI が「削除していい」と言っても、ブロック対象は選択できません。

  • ゴミ箱だけ

    選んだ対象は、最終確認ダイアログのあとでゴミ箱へ移動します。 完全削除は行いません。Finder から元に戻せます。

  • ハードブロックが最優先

    システム領域、認証情報、鍵や秘密情報らしいファイル、Git リポジトリ、 ホームと /Applications の外側などは選べません。 元 CLI の保護フォルダや「システム/ツール管理」判定も守ります。

  • 移動直前に Rust が再確認

    ゴミ箱へ移す直前に、Rust 側でもう一度ハードブロックを確認します。 安全に関わる最終チェックは、ネイティブ側に置いてあります。

  • AI より慎重なルール

    AI が「消しちゃダメ」と判定したものは選択できません。 写真・ムービー・ミュージックなど個人データのカテゴリや「使用中のデータ」は、 AI が「削除していい」と言っても「注意」に下げます。

ハードブロックと保護の対象（例）

元 CLI の保護

/、ホーム、~/Library、~/Library/Keychains、 Preferences、Mail、Messages など。 元 CLI が「システム/ツール管理」と判定したもの（Homebrew、Docker など）も含まれます。

このアプリで追加したハードブロック

/System・/private・/usr などのシステム領域、キーチェーン、 ~/.ssh・~/.gnupg・~/.aws・~/.kube・~/.config/gh などの認証情報、id_rsa*・*.pem・*.key・*.p12・.env などの鍵や秘密情報らしいファイル、.git とその中身、.git を含むリポジトリのフォルダ、 ホームフォルダと /Applications の外側。

Privacy

AI に送るのはメタデータだけ

スキャン・サイズ計測・日付取得・ゴミ箱移動は、すべてこの Mac の中だけで行います。 ファイルの中身は送りません。

  • 送るのはメタデータのみ

    パス、名前、拡張子、ファイル/フォルダの別、サイズ、最終使用日、更新日、 元 CLI のカテゴリ・判定・理由です。中身の読み取りやアップロードはありません。

  • 送る前に JSON を確認

    「この情報を OpenAI に送ります」というダイアログで、実際に送る JSON をそのまま確認できます。 見てから送るかどうかを決められます。

  • パスとユーザー名は初期状態で隠す

    ホームフォルダ（/Users/あなた → ~）とユーザー名（→ <user>）を隠すオプションがあり、 初期状態でオンです。

Sign in with ChatGPT

Sign in with ChatGPT のデモアプリです

AI 判定には、OpenAI の Sign in with ChatGPT のうち 「ChatGPT プランの使用量を使う」機能を使っています。 API キーは不要です。このアプリはオープンソースで、お使いの Mac 上でローカルに動作します。 ChatGPT の会話履歴やメモリにはアクセスしません。

  • 対象アプリ（公式ドキュメントの条件） オープンソースのアプリと、ローカルで動く個人プロジェクト（ほかに一部の非公開アプリ）。 このアプリはその条件に沿っています。
  • 対象ユーザー 公式 Cookbook では「対象となる ChatGPT Plus と Pro のユーザー」と説明されています。 利用するかどうかは、ブラウザの同意画面で選べます。許可しなかった場合、AI 判定は使えません（元 CLI のルール判定は使えます）。
  • 使用量 ChatGPT の設定 → 使用量で確認でき、アプリごとの上限も設定できます。 ドキュメントによると、Plus の 5 時間ごとの使用上限はこのアプリを含むすべてのアプリで共有され、 アプリごとに別枠はありません（Pro には 5 時間上限は適用されません）。
  • プレビュー 現在はプレビューで、store: false と stream: true が必須、 画像生成やファイル検索などのツールは使えない、といった制限があります。仕様は変わる可能性があります。
  • 独自実装（公式 DevKit は未使用） 公式 DevKit は非商用ライセンスのため、このリポジトリの MIT ライセンスと条件が合いません。 コードやブランド素材は使っていません。ドキュメントを読んで独自に実装しています。 ボタンはロゴなしのテキスト（「Continue with ChatGPT」）です。 トークンは macOS のキーチェーンに保存し、Web ビュー側には渡しません。
